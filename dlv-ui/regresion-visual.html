Regresión visual del renderizador (F5-12, obligatoria por ADR-006)

Comprueba posición, color y fondo del renderizador WebGL2 con datos sintéticos y deterministas, comparando contra un oráculo geométrico calculado a mano —no contra una imagen de referencia guardada—. El porqué de esa elección está en la cabecera de src/render/regresion-visual/invariantes.ts.

Ábrelo con npm run dev, o sin manos con npm run regresion-visual:edge (levanta Vite, lo abre en Edge sin cabeza y devuelve un código de salida). Si el veredicto global dice NO MEDIDO, esta máquina o navegador no tiene WebGL2 utilizable: no es un aprobado, es que no se pudo mirar (§8.10).

La línea backend del resultado dice QUIÉN rasterizó. Si pone SOFTWARE, lo que se ha comprobado sigue siendo válido —posición, color y cobertura no dependen del rasterizador— pero no dice nada de la GPU real de esta máquina.
